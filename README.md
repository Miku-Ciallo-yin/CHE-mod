# TAHS

> Among Us 职业模组 — 参考 TONE（TownOfNewEpic）架构，为游戏增加更多职业和中立阵营。
>
> 开发者：**米裤恰油**

## 环境

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Among Us (Steam) | 2026.3.31 | 直接引用游戏目录 `BepInEx\interop` 中已生成的互操作程序集 |
| BepInEx.Unity.IL2CPP | 6.0.0-be.735 | 模组加载器 |
| HarmonyX | 2.10.2 | 方法补丁库 |
| .NET SDK | 6.0+（目标框架 net6.0） | 开发构建 |

以上版本与游戏目录 `D:\st\steamapps\common\Among Us\CNE` 中的实际运行环境一致（编译直接引用该目录 `BepInEx\interop` 的互操作程序集）。

## 构建

```bash
dotnet build
```

编译成功后 `TAHS.dll` 会自动复制到 csproj 中 `AmongUsPluginsDir` 指定的
`BepInEx\plugins` 目录（留空该属性可关闭自动部署），启动游戏即可加载。

## 目录结构

```

    ├── ModGameOptionsMenu.cs  # 设置 UI 共享状态（页签编号/布局常量）
    ├── ModSettingsMenuPatch.cs # 设置菜单页签：模板克隆、按钮、ChangeTab 拦截
    ├── ModOptionsMenuPatch.cs # 页签内容构建（参考 TOHE，Initialize/CreateSettings 接管）
    ├── RoleUpdatePatch.cs    # 职业技能驱动（每帧 OnUpdate）
    ├── MurderPatch.cs        # 击杀结算钩子（OnMurder）

    ├── ImpostorVisionPatch.cs # 内鬼不互认（名字颜色覆盖，对局+会议）
    ├── GuesserPatch.cs       # 赌怪：会议准星标记 + 猜测面板
    ├── ForceEndPatch.cs      # /end 聊天命令 + ALT+F4 强制结束（仅主机对局中）
    ├── TestModePatch.cs      # 测试模式：跳过正常结束判定
    ├── StartAnyCountPatch.cs # 取消开局人数下限（保留倒计时）+ /start 命令
    ├── MainMenuPatch.cs      # TONE 风格主菜单：版本徽章 + 关于/GitHub/交流群按钮
    └── EndGamePatch.cs       # 结算画面覆盖（自定义胜利者）
```

## 职业一览

| 职业 | 类型 | 能力 |
| --- | --- | --- |
| 小丑 Jester | 中立 | 被投票放逐即单独获胜 |
| 佃农 Farmer | 船员（可转化） | 靠近船员概率抢夺其任务；抢够数量并完成现有任务后按 `Q` 击杀最近玩家；误杀船员则转为中立阵营 |
| 美警 Cop | 船员（可转内鬼） | 按 `Q` 击杀：中立/内鬼则对方死，船员则自杀抵命；贴近深色船员数秒后自动击杀；自动击杀满人数后转为内鬼，CD 跟随全局设置 |
| 懦弱者 Coward | 中立（敌对） | 开局带刀（CD 跟随全局设置）；杀满 3 人后贴近某人 5 秒转变为其阵营：船员→失去击杀，内鬼→保留击杀，中立→变为对方职业并共同胜利（一方再转变则失效） |
| 忏悔者 Repenter | 内鬼（可转船员） | 带刀（CD 跟随全局设置）；杀满人数后按 `F` 变形为船员，失去击杀能力并在倒计时后自裁，自裁者无法胜利 |
| 内阁 Minister | 船员 | 自动变为黑色、无法被赌；限时完成全部任务否则自杀；完成后夺取其他船员任务；美警贴近即秒杀（不计入转变人数）；击杀内阁的中立/内鬼若一轮会议前不再击杀则变为内阁（跟随船员胜利） |
| 使徒 Apostle | 船员 | 存活时全员可用 `/kc` 查存活内鬼/中立人数；会议中可见死者阵营（红内鬼/灰中立/青船员）与死因；每完成一个任务随机赐予船员良性附加职业 |
| 月跑入机 MoonRunner | 中立（友好） | Q 对最近玩家施加速度增益（可叠加至最大值）；最大值后双方身份透露且无法被赌；转增益他人则前者限时追杀后者（前者受保护、后者被标记），超时前者自杀无法胜利、后者与月跑入机共同胜利；同时 2 人最大值则直接共同胜利 |
| 中东机长 Pilot | 内鬼 | Shift 释放冲刺：沿移动方向直线冲刺撞墙爆炸；沿途与爆炸范围击杀（可配误杀队友/自身存活），冲刺由主机驱动无模组端同样生效 |
| 转换者 Converter | 船员 | 会议中投票键选两人：前者转变为后者职业并得知前者原职业；正常投票用 /vote；弃票则本轮技能锁定可正常投票；次数用尽变白板直接投票 |
| 平衡主义者 Balancer | 船员 | 某阵营人数超过开局人数时得知（不知哪个阵营）；用 `/ph` 随机处决超编阵营一名玩家（次数可配） |
| 赌怪 Guesser | 附加 | 会议中点击他人名牌前的准星打开猜测面板，猜中其职业则对方死亡，猜错自己死亡 |

## 主菜单自定义背景

把一张图片命名为 `background.png` 放入游戏目录 `TAHS-DATA\`（如 `Among Us\CNE\TAHS-DATA\background.png`），
即可替换主菜单背景（建议二次元人物图，16:9）。不放则使用程序生成的星空渐变背景。

## 配置

两种方式，游戏内选项优先：

- **大厅设置菜单（推荐）**：创建房间后打开"游戏设置 → 编辑"，顶部页签除原版的
  预设 / 游戏设置 / 职业设置外，新增 **"模组设置"** 和 **"职业设置"** 两个 TAHS 页签：
  - 模组设置：全局功能开关（内鬼互认等），平铺调整。
  - 职业设置：一级为职业名称按钮（右侧显示当前生成概率），点击职业名进入该职业的配置页面，
    "← 返回"回到职业列表。
  仅主机可修改，修改后经 RPC 同步给所有客户端。
- **BepInEx 配置文件**：`BepInEx\config\com.mikuqiayou.che.cfg`（首次运行自动生成），
  仅作为游戏内选项的**默认值**，改完重启游戏生效。

## 聊天指令

| 指令 | 作用 | 限制 |
| --- | --- | --- |
| `/start [秒数]` | 以指定倒计时开始游戏（默认 5 秒） | 仅主机、大厅中 |
| `/end` | 强制结束对局返回大厅 | 仅主机、对局中 |
| `/dump` | 导出当前日志到桌面（`TAHS-Log-时间戳.txt`），并在聊天栏显示最近 8 行 | 仅房主 |
| `/help` | 显示全部指令及功能 | 无 |
| `/id` | 显示所有玩家的名字及其对应 ID | 无 |
| `/m` | 查看自己本局职业介绍（含附加职业） | 无 |
| `/r` | 查看本局已开启的全部职业 | 无 |
| `/d` | 死亡后查看击杀自己的玩家（名字+职业） | 无 |
| `/l` | 查看上一局身份转换详情及击杀记录（含初始分配） | 无 |
| `/addmod <ID>` | 将该 ID 玩家加入协管名单（TAHS-DATA/Moderators.txt） | 仅房主 |
| `/s <内容>` | 发布醒目公告（屏幕大字 + 聊天广播，全员可见） | 房主/协管 |
| `/vote <ID>` | 会议中投票给对应 ID 的玩家 | 无 |
| `/ph` | 平衡主义者：处决超编阵营随机一名玩家 | 平衡主义者 |
| 转换者：技能可使用次数 | 2 | 转换者技能使用次数（1~10） |
| 平衡主义者：技能可使用次数 | 2 | 平衡主义者处决次数（1~10） |

## 协管名单

- 模组设置 → **协管名单**：开启后名单内玩家获得协管权限，下级子权限可分别开关：
  - 协管权限：/start（默认开）
  - 协管权限：/s（默认开）
  - 协管权限：/end与ALT+F4（默认开）
- 名单文件：游戏目录 `TAHS-DATA\Moderators.txt`，每行一个好友代码（FriendCode），可手动编辑
- 房主输入 `/addmod <玩家ID>` 自动写入名单（先用 `/id` 查 ID）
- 协管的指令经 RPC 由主机验证后执行（Host Only 原则）

## 黑名单与反作弊

- **黑名单**：`TAHS-DATA\BanList.txt`（每行一个好友代码），名单内玩家进房即被踢出封禁，无法进入游戏
- **反作弊**（主机判定）：非内鬼且无合法带刀职业的玩家触发击杀即判定作弊，按模组设置中的
  **作弊处理方式** 执行：警告（聊天广播）/ 踢出 / 封禁 / 加入黑名单（自动写入 BanList.txt 并封禁）
| `/bt <ID> <职业>` | 猜测该 ID 玩家的职业，猜对目标死、猜错自己死（如 `/bt 2 佃农`） | 有猜测权限者 |

## 添加新职业 / 附加职业

- 主职业：在 `TAHS/Roles/<阵营>/` 下新建类继承 `RoleBase`，在 `CustomRoleManager.RoleRegistry` 注册 `(新ID, () => new YourRole())`。
- 附加职业：在 `TAHS/Roles/Addons/` 下新建类继承 `AddonBase`，在 `CustomRoleManager.AddonRegistry` 注册（ID 与主职业同空间，勿冲突）。

注册后自动生成"生成概率"设置项并归入对应分类页，ID 用于 RPC 同步，不要改动已有 ID。

## 联机说明（Host Only 架构）

**只需主机安装本模组**，客户端不安装也可以正常游玩（与 TONE 的 Host Only 模式一致）：

- **职业分配**：主机随机分配并广播（CallId 217），模组端应用；无模组客户端忽略该 RPC，由主机驱动其职业逻辑。
- **选项值**：主机在大厅调整后经 RPC（CallId 218）同步给模组端。
- **佃农**：抢夺逻辑完全在主机执行——即使佃农是无模组客户端，主机也会驱动其靠近船员时抢夺对方任务（走官方 `RpcSetTasks` 转移，各端天然同步）；
  击杀按键 `Q` 在主机本地直接生效，非主机模组端按 Q 经击杀请求 RPC（CallId 219）由主机验证执行。
- **小丑获胜 / 结算**：主机检测放逐并强制结束游戏，无模组客户端看到原版结算画面（文字不同，属正常）。
- 私有名牌（PrivateTag）：主机用定向 SetName RPC 只给指定客户端改名，
  实现"无模组端可见 + 仅某人可见"。已用于：使徒看死者阵营·死因、
  转换者看被转换者的新阵营。
- 无模组客户端的固有降级：不显示职业名 UI、无法使用赌怪（会议准星是模组端 UI）。
  月跑入机已做特别处理：无模组端被增益由主机 RpcSnapTo 助推加速、
  追杀者靠近目标自动出刀（无需按键）。
- 模组握手：模组端进房时经 RPC（CallId 227）告知主机，用于区分两种客户端。
- 模组端联机建议都安装以获得完整体验。

## 玩家 ID

主机为每个玩家分配 ID：**房主 = 0，其余按进入房间顺序从 1 递增**（中途有人退出不重排，取最小未占用值）。
分配结果经 RPC（CallId 220）同步给模组端，名牌前显示青色 `[id]` 前缀（大厅和对局内均显示）。
返回主菜单后清空，下一局重新分配。无模组客户端不显示前缀（固有降级）。
