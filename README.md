## 构建

```bash
dotnet build
```

编译成功后 `TAHS.dll` 会自动复制到 csproj 中 `AmongUsPluginsDir` 指定的
`BepInEx\plugins` 目录（留空该属性可关闭自动部署），启动游戏即可加载。

## 公开房间（社区服务器）

**官方服开模组公开房有被官方反作弊封禁的风险。** 参考 TONE/EHR 的做法，
模组启动时会自动向服务器列表注入两个社区服（与 TONE 同名，共存不重复）：

- **Niko-AS**（亚洲社区服）
- **Niko-CN**（中国社区服）

用法：在线游戏界面点右上角服务器选择，切到 **Niko-AS** 或 **Niko-CN**，
再创建公开房间即可。社区服不受官方反作弊管辖，模组公开房安全；
且社区服之间玩家互通，无模组客户端也能加入（职业逻辑由房主驱动）。

## 官方服房间隔离与反封禁

参考 TONE 的官方服方案，模组在官方服务器上自动做三件事：

- **版本分池**：官方服上模组端把广播版本号抬升 +25，官方匹配按版本分池——
  模组房（包括公开房）**不会出现在原版房间列表**，只有模组端能看到和加入；
  原版端也无法凭房间代码加入官方服模组房（版本不匹配）。
- **自报模组身份**：`Constants.IsVersionModded` 恒为 true，
  官方反作弊将会话识别为模组会话，模组房内的自定义 RPC 不按作弊处理。
- **大包拦截**：官方服会踢出发送超大包（>1200 字节）的客户端，模组在发送前拦截。

因此官方服可以正常开模组公开房游玩（只对模组玩家可见）；
要与无模组端混玩，请用社区服（见下节，社区服不做版本隔离，保持互通）。

## 主菜单自定义背景

把一张图片命名为 `background.png` 放入游戏目录 `TAHS-DATA\`（如 `Among Us\CNE\TAHS-DATA\background.png`），
即可替换主菜单背景（建议二次元人物图，16:9）。不放则使用程序生成的星空渐变背景。

## 配置

两种方式，游戏内选项优先：

- **大厅设置菜单（推荐）**：创建房间后打开"游戏设置 → 编辑"，顶部页签除原版的
  预设 / 游戏设置 / 职业设置外，新增 **"模组设置"** 和 **"职业设置"** 两个 TAHS 页签：
  - 模组设置：全局功能开关（内鬼互认等），平铺调整；底部为**预设方案**——
    点击"预设方案"在 5 个预设间切换并读取，"保存当前设置到该预设"把当前全部选项
    存入 `TAHS-DATA\Preset{编号}.txt`，重启游戏自动沿用上次选择的预设。
  - 职业设置：一级为职业名称按钮（右侧显示当前生成概率），点击职业名进入该职业的配置页面，
    "← 返回"回到职业列表。附加职业分类下再分 **良性 / 恶性 / 内鬼** 三个分组，
    点击分组进入该组附加职业列表。
  仅主机可修改，修改后经 RPC 同步给所有客户端。
- **BepInEx 配置文件**：`BepInEx\config\com.mikuqiayou.che.cfg`（首次运行自动生成），
  仅作为游戏内选项的**默认值**，改完重启游戏生效。

## 聊天指令

| 指令 | 作用 | 限制 |
| --- | --- | --- |
| `/start [秒数]` | 以指定倒计时开始游戏（默认 5 秒） | 房主/协管、大厅中；无模组协管由主机代收执行 |

## 协管名单

- 模组设置 → **协管名单**：开启后名单内玩家获得协管权限，下级子权限可分别开关：
  - 协管权限：/start（默认开）
  - 协管权限：/s（默认开）
  - 协管权限：/end与ALT+F4（默认开）
- 名单文件：游戏目录 `TAHS-DATA\Moderators.txt`，每行一个好友代码（FriendCode），可手动编辑
- 房主输入 `/addmod <玩家ID>` 自动写入名单（先用 `/id` 查 ID）
- 协管的指令经 RPC 由主机验证后执行（Host Only 原则）

## 黑名单与反作弊

- **黑名单**：`TAHS-DATA\BanList.txt`（每行一个好友代码），名单内玩家进房即被踢出封禁，无法进入游戏
- **反作弊**（主机判定）：非内鬼且无合法带刀职业的玩家触发击杀即判定作弊，按模组设置中的
  **作弊处理方式** 执行：警告（聊天广播）/ 踢出 / 封禁 / 加入黑名单（自动写入 BanList.txt 并封禁）
| `/bt <ID> <职业>` | 猜测该 ID 玩家的职业，猜对目标死、猜错自己死（如 `/bt 2 佃农`） | 有猜测权限者 |

## 添加新职业 / 附加职业

- 主职业：在 `TAHS/Roles/<阵营>/` 下新建类继承 `RoleBase`，在 `CustomRoleManager.RoleRegistry` 注册 `(新ID, () => new YourRole())`。
- 附加职业：在 `TAHS/Roles/Addons/` 下新建类继承 `AddonBase`，在 `CustomRoleManager.AddonRegistry` 注册（ID 与主职业同空间，勿冲突）。

注册后自动生成"生成概率"设置项并归入对应分类页，ID 用于 RPC 同步，不要改动已有 ID。

## 联机说明（Host Only 架构）

**只需主机安装本模组**，客户端不安装也可以正常游玩（与 TONE 的 Host Only 模式一致）：

- **职业分配**：主机随机分配并广播（CallId 217），模组端应用；无模组客户端忽略该 RPC，由主机驱动其职业逻辑。
- **选项值**：主机在大厅调整后经 RPC（CallId 218）同步给模组端。
- **佃农**：抢夺逻辑完全在主机执行——即使佃农是无模组客户端，主机也会驱动其靠近船员时抢夺对方任务（走官方 `RpcSetTasks` 转移，各端天然同步）；
  击杀按键 `Q` 在主机本地直接生效，非主机模组端按 Q 经击杀请求 RPC（CallId 219）由主机验证执行。
- **小丑获胜 / 结算**：主机检测放逐并强制结束游戏，无模组客户端看到原版结算画面（文字不同，属正常）。
- 私有名牌（PrivateTag）：主机用定向 SetName RPC 只给指定客户端改名，
  实现"无模组端可见 + 仅某人可见"。已用于：使徒看死者阵营·死因、
  转换者看被转换者的新阵营、叛徒互认红名（名字染色，无模组端同样可见）。
- 无模组客户端的固有降级：不显示职业名 UI、无法使用赌怪（会议准星是模组端 UI）。
  叛徒：无模组端结算画面按原版身份显示胜负（模组端才会把叛徒并入/剔出胜利名单）。
  月跑入机已做特别处理：无模组端被增益由主机 RpcSnapTo 助推加速、
  追杀者靠近目标自动出刀（无需按键）。
- 模组握手：模组端进房时经 RPC（CallId 227）告知主机，用于区分两种客户端。
- 大厅自由行动（参考 TONE，模组端）：等待大厅按住 Ctrl 穿墙到飞船外面；
  滚轮缩放视角（等待大厅及对局死亡后可用）；/tpout、/tpin 传送出/回飞船。
  位置同步走原版 NetTransform，无模组客户端也能看到飞出船外的人。
  无模组端使用 /tpout、/tpin：主机从聊天代收指令并用 RpcSnapTo 代为传送，
  反馈私信仅发起者可见；模组端看不到聊天中的指令原文（一律隐藏），
  无模组端之间仍能看到彼此发出的指令（原版聊天广播无法拦截）。
- 模组端联机建议都安装以获得完整体验。

## 玩家 ID

主机为每个玩家分配 ID：**房主 = 0，其余按进入房间顺序从 1 递增**（中途有人退出不重排，取最小未占用值）。
分配结果经 RPC（CallId 220）同步给模组端，名牌前显示青色 `[id]` 前缀（大厅和对局内均显示）。
返回主菜单后清空，下一局重新分配。无模组客户端不显示前缀（固有降级）。
